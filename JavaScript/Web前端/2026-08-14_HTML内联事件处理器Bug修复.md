# Bug 修复：HTML 内联事件处理器与 JS 函数定义

> **日期**：2026-08-14
> **标签**：#JavaScript #HTML #Debug #前端

---

## 一、Bug 描述

`day1-agent-event.html` 页面中所有按钮点击无响应，包括：
- 源码展开/收起按钮（`onclick="toggleCollapse(this)"`）
- 参考答案显示/隐藏按钮（`onclick="toggleAnswer(this)"`）

---

## 二、根因分析

HTML 中所有按钮都使用了内联事件处理器：

```html
<button onclick="toggleCollapse(this)">展开源码</button>
<button onclick="toggleAnswer(this)">显示答案</button>
```

但 `toggleCollapse` 和 `toggleAnswer` 这两个函数从未在 `<script>` 标签中定义。

**关键原理**：HTML 的 `onclick` 属性引用的是全局作用域中的函数。如果该函数未在 JS 中定义，浏览器会静默失败，不会抛出明显错误，导致按钮点击完全无响应。

---

## 三、修复方案

在 `<script>` 标签开头添加两个全局函数：

```javascript
function toggleCollapse(btn) {
  btn.classList.toggle('open');
  const content = btn.nextElementSibling;
  if (content) content.classList.toggle('show');
}

function toggleAnswer(btn) {
  const content = btn.nextElementSibling;
  if (content) content.classList.toggle('show');
}
```

| 函数 | 作用 | CSS 类切换 |
|------|------|-----------|
| `toggleCollapse(btn)` | 展开/收起源码 | `.collapsible-toggle` 的 `open` 类 + `.collapsible-content` 的 `show` 类 |
| `toggleAnswer(btn)` | 显示/隐藏参考答案 | `.answer-content` 的 `show` 类 |

刷新页面即可生效。

---

## 四、经验教训

1. **HTML 内联事件处理器引用的是全局作用域函数**，必须在 `<script>` 中定义对应的全局函数
2. **浏览器静默失败**：内联事件处理器引用的函数不存在时，浏览器不会报错，需要开发者主动排查
3. **适用场景**：任何使用 `onclick`、`onchange` 等内联事件处理器的 HTML 页面，务必确保对应的 JS 函数已定义
