## 🚀 快速开始

### 新建一个练习代码

根据使用的语言，直接将代码放入对应目录即可。例如：

- Java 数组练习 → `Java/基础语法/ArrayDemo.java`
- C 语言链表实现 → `C/数据结构/LinkedList.c`
- LeetCode 题解 → `Java/算法练习/LeetCode_001_TwoSum.java`

### 使用项目模板

需要新建一个完整项目时，从 `templates/` 复制对应模板：

```bash
# 示例：新建一个 Java Maven 项目
cp -r templates/java-maven Java/项目实战/我的新项目
```

## 📝 代码规范

### 通用原则

1. **文件命名**：使用英文，见名知意
   - 好：`BinarySearch.java`、`linked_list.c`
   - 避免：`新建文本文档.java`、`test1.c`
2. **编码格式**：统一使用 **UTF-8**
3. **注释**：关键逻辑必须加注释，复杂算法附思路说明

### Java 规范

- 类名：大驼峰 `UserService`
- 方法名/变量名：小驼峰 `getUserName`
- 常量：全大写下划线 `MAX_SIZE`

### C 规范

- 函数/变量：下划线命名 `create_node`
- 宏定义：全大写 `#define MAX_LEN 100`

### JavaScript 规范

- 变量/函数：小驼峰 `fetchData`
- 常量：全大写下划线 `API_URL`

### Python 规范

- 遵循 PEP8
- 函数/变量：下划线命名 `calculate_sum`

## 💾 Git 提交规范

### Commit Message 格式

```
<type>(<scope>): <subject>
```

### type 类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新增功能/代码 | `feat(Java): 添加二分查找实现` |
| `fix` | 修复 Bug | `fix(C): 修复链表删除逻辑错误` |
| `docs` | 文档/笔记更新 | `docs: 新增多线程学习记录` |
| `style` | 代码格式调整（不影响逻辑） | `style: 格式化代码` |
| `refactor` | 代码重构 | `refactor(Python): 重构爬虫逻辑` |
| `test` | 测试相关 | `test: 添加单元测试` |
| `chore` | 构建/配置/其他 | `chore: 更新 .gitignore` |

### 提交示例

```bash
git commit -m "feat(Java/数据结构): 实现二叉树的前中后序遍历"
git commit -m "docs(学习记录): 完成 2026-08-03 Java IO 流学习"
```

## 🎯 学习方法论建议

1. **费曼学习法**：学完尝试用自己的话写出来或讲给别人听
2. **5 分钟启动法**：不想学的时候，先告诉自己只学 5 分钟
3. **小步快跑**：代码拆小块，每次提交一个独立功能点
4. **错题本**：做错的算法题单独标记，定期回顾
5. **项目驱动**：学完语法尽快做小项目巩固
