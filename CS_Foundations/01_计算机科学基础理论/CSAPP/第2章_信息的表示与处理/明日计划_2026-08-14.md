### 必做手算

用 4 位二进制，手算补码表示范围：

```
位模式    无符号值    补码值
0000        0          0
0001        1          1
...
0111        7          7
1000        8         -8  ← TMin，没有对应的正数
1001        9         -7
...
1111       15         -1
```

**关键理解：** 补码最高位权重为负（-2^(w-1)），不是简单的"取反加一"。

### 验证代码

```c
#include <stdio.h>
#include <limits.h>

int main() {
    // 1. 打印 int 的范围
    printf("INT_MIN = %d\n", INT_MIN);  // -2147483648
    printf("INT_MAX = %d\n", INT_MAX);  //  2147483647
    printf("INT_MIN 的绝对值会溢出吗？\n");

    // 2. TMin 取负 = 自己（这是唯一的例外）
    int tmin = INT_MIN;
    printf("-TMin = %d\n", -tmin);  // 还是 -2147483648！

    // 3. 预测 → 执行 → 对比
    // 预测：0xFFFFFFFF 作为 unsigned 和 int 分别是什么？
    unsigned u = 0xFFFFFFFF;
    int      i = 0xFFFFFFFF;
    printf("unsigned: %u\n", u);  // 4294967295
    printf("int:      %d\n", i);  // -1（位模式相同，解释不同）

    return 0;
}
```
