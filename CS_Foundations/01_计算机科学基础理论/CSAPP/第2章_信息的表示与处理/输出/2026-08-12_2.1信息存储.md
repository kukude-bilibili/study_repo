## 一、核心概念

### 1. 字节（Byte）

字节是最小的可寻址内存单位，不是独立的比特（bit）。

```
1 byte = 8 bit
```

### 2. 虚拟内存（Virtual Memory）

机器级程序将内存视为一个巨大的字节数组。内存中每个字节拥有唯一数字标识，称为**地址**；所有合法地址的集合，称为**虚拟地址空间**（virtual address space）。

### 3. C 语言指针

C 编译器会把指针与数据类型绑定，生成不同机器指令，访问指针指向位置对应类型的值。

### 4. 程序对象

程序对象 = 一段字节块；程序本身本质就是字节序列。

## 二、进制转换练习

十六进制 ↔ 二进制换算规则：**1 位十六进制 = 4 位二进制**

| 十六进制 | 二进制 | 十六进制 | 二进制 |
|:--------:|:------:|:--------:|:------:|
| 0 | 0000 | 8 | 1000 |
| 1 | 0001 | 9 | 1001 |
| 2 | 0010 | A | 1010 |
| 3 | 0011 | B | 1011 |
| 4 | 0100 | C | 1100 |
| 5 | 0101 | D | 1101 |
| 6 | 0110 | E | 1110 |
| 7 | 0111 | F | 1111 |

**A. 0x39A7F8 → 二进制**

```
3=0011, 9=1001, A=1010, 7=0111, F=1111, 8=1000
结果：0011 1001 1010 0111 1111 1000
```

**B. 二进制 1100100101111011 → 十六进制**

```
从右往左 4 位分组：1100 1001 0111 1011
1100=C, 1001=9, 0111=7, 1011=B
结果：0xC97B
```

**C. 0xD5E4C → 二进制**

```
D=1101, 5=0101, E=1110, 4=0100, C=1100
结果：1101 0101 1110 0100 1100
```

**D. 二进制 1001101110011110110101 → 十六进制**

```
从右向左每 4 位分组：10 0110 1110 0111 1011 0101
高位不足 4 位左边补 0 → 0010 0110 1110 0111 1011 0101
0010=2, 0110=6, 1110=E, 0111=7, 1011=B, 0101=5
结果：0x26E7B5
```
