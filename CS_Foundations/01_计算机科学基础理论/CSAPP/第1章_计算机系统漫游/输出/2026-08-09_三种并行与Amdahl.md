# CSAPP 三种并行层次

## 1. 线程级并发
多个CPU为一个核，一个核可以处理多个线程(2个)
- 超线程：又称同时多线程，是一项允许一个CPU执行多个控制流的技术。

## 2. 指令级并行
在较低的抽象层次上，现代处理器可以同时执行多条指令的处理器称为指令级并行
- 超标量（super‑scalar）处理器：处理器可以达到比一个周期一条指令更快的执行速率。

## 3. 单指令、多数据并行
在最低层次上，许多现代处理器拥有特殊的硬件，允许一条指令产生多个可以执行的操作，这种方式称为单指令、多数据，即SIMD并行。例如，较新几代的Intel和AMD处理器向量数据类型(？)

### 逐条

**1. 线程级并发**

> 多个CPU为一个核

**说反了。** 应该是：**一个 CPU 芯片包含多个核**，每个核可以独立执行。你写的变成"多个 CPU 组成一个核"，逻辑反了。

> 超线程：又称同时多线程，是一项允许一个CPU执行多个控制流的技术。

正确。更精确：一个物理核模拟出两个逻辑核，让两个线程的指令交替进入执行单元。

**2. 指令级并行**

定义正确。超标量 = 一个时钟周期发射多条指令，流水线 + 多执行单元。

你的图 ③ 想表达的是：指令 A、B、C 的不同阶段（取指/译码/执行/写回）同时在不同硬件单元上跑。思路对，这就是流水线叠加超标量的效果。

**3. SIMD**

> 向量数据类型(？)

你问号的地方正是答案：SIMD 操作的是一组打包好的数据，这组数据就叫**向量**。比如一条指令同时对 8 个 int 做加法，这 8 个 int 就是一个向量。

**4. Amdahl 费曼讲解**

```

v→∞
1s → 0s
```

**这个费曼讲得很好。** 翻译一下你说的：

> 一个任务 100s，其中 50% 可以加速。就算把这 50% 加速到瞬间完成（v→∞），那 50s 变成 0s，总时间也只能从 100s 降到 50s。加速比最多 2 倍。

一句话讲透 Amdahl 定律——**瓶颈在不能加速的部分。** 这个费曼讲解过关，可以拿去给别人讲了。
