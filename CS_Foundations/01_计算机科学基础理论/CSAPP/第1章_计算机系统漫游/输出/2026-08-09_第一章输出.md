操作系统保持跟踪进程运行所需的所有状态信息。这种状态，也就是上下文，包括许多信息，比如PC和寄存器文件的当前值，以及主存的内容。当操作系统决定要把控制权从当前进程转移到某个新进程时，就会切换上下文切换，即保存当前进程的上下文、恢复新进程的上下文，然后将控制权传递到当前新进程。新进程就会从他上次停止的地方开始。

### Amdahl 定律推导

设 α = 可改进部分执行时间占比，原始总时间 = T_old

```
可改进部分时间  = α * T_old
不可改进部分时间 = (1-α) * T_old

设改进后该部分加速 k 倍，则改进后该部分时间 = (α * T_old) / k

改进后总时间:
T_new = (1-α) * T_old + (α * T_old) / k
      = T_old * (1-α + α/k)

整体加速比:
S = T_old / T_new = 1 / (1-α + α/k)
```

当 k → ∞（某部分无限加速），S → 1/(1-α)，永远不会超过这个上限。

- 并行：用并发使一个系统运行得更快

**5. Amdahl 定律**

**能自己推公式，说明你在认真学。** 但推导有混淆：

标准 Amdahl 定律：

> 设 α = 可改进部分的执行时间占比，k = 改进部分的加速倍数
>
> 改进后：`T_new = (1-α)·T_old + (α·T_old)/k`
>
> 整体加速比：`S = T_old/T_new = 1 / ((1-α) + α/k)`
